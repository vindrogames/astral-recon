The project is a game that is built in javascript, we have the menu loader, the level loader and now the player can move around
It is been programmed using the framework Phaser.io in javascript
the level loads different rooms defined as CSVs, where the tiles are indicated
5,6,8,9,10,11,12,13 are walls that the player cannot pass
16 indicates the door that the player will be able to cross, after it has got the key
2 indicates that the player can pass normally
3 the player should die
